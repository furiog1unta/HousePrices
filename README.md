# HousePrices

Учебный проект по соревнованию Kaggle [House Prices: Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques): предсказание цены дома по его характеристикам.

- **Задача:** регрессия, таргет `SalePrice`
- **Данные:** 1460 домов в train, 1459 в test, 79 признаков
- **Метрика:** RMSE между логарифмами предсказанной и реальной цены (метрика соревнования)

## Ноутбуки

**01_EDA** — разведочный анализ: распределение таргета, корреляции с ценой, мультиколлинеарные пары признаков (`GarageArea`/`GarageCars`, `GrLivArea`/`TotRmsAbvGrd`, `TotalBsmtSF`/`1stFlrSF`), признаки с долей пропусков больше 70%.

**02_data_processing** — подготовка данных:
1. Удаление признаков, которые слабо связаны с ценой, сильно коррелируют с другими или почти пусты
2. Заполнение пропусков: `'None'` или `0` там, где NaN означает отсутствие объекта (нет гаража, подвала и т.п.), остальное — по статистикам train
3. Ordinal-кодирование оценок качества (`Po < Fa < TA < Gd < Ex`)
4. One-hot кодирование номинальных признаков, выравнивание колонок test по train
5. `log1p` для таргета (`LogSalePrice`) и признаков со скошенным распределением
6. Стандартизация небинарных признаков по `mean`/`std` из train

**03_model_selection** — сравнение восьми моделей (линейные, деревья, бустинги) на 5-fold кросс-валидации (`KFold`, `shuffle=True`) и грубый подбор гиперпараметров через `RandomizedSearchCV`. Для дальнейшей работы отобраны три лучшие модели: XGBoost, CatBoost и Lasso.

**04_final_submission** — подбор гиперпараметров XGBoost, CatBoost и Lasso в Optuna (TPE-сэмплер, 50 trials на модель, та же 5-fold кросс-валидация). Лучшая модель, CatBoost, обучается на всём train. Предсказания переводятся из логарифмов обратно через `expm1` и сохраняются в `submissions/submissioncatboost.csv`.

**NN** — полносвязная сеть на PyTorch (196 → 128 → ReLU → 1) на тех же обработанных данных. Обучение: `AdamW` (lr=1e-3), `MSELoss`, батч 16, до 50 эпох, `ReduceLROnPlateau` и ранняя остановка по валидации. Валидация — hold-out 30% от train. Веса лучшей эпохи сохраняются в `best_model.pt`, предсказания на test — в `submissions/NNsubmission.csv`.

## Результаты

RMSE на логарифме цены. **CV** — 5-fold кросс-валидация на train после подбора гиперпараметров в Optuna, **LB** — public leaderboard Kaggle:

| Модель | CV | LB |
|---|---|---|
| CatBoost | **0.13200** | **0.12901** |
| XGBoost | 0.13201 | — |
| Lasso | 0.13447 | — |

На Kaggle отправлялись только предсказания CatBoost. На leaderboard он показал результат чуть лучше, чем на кросс-валидации.

Нейросеть получила RMSE ≈ 0.148 на hold-out валидации. Напрямую с таблицей эту цифру сравнивать нельзя: валидация другая (один сплит вместо 5-fold), и по ней же выбиралась лучшая эпоха. Сеть заметно переобучается (train RMSE ≈ 0.074), регуляризация пока не настроена.

## Запуск

Нужен Python 3.14.

```bash
pip install -r requirements.txt
```

Ноутбуки запускаются по порядку: `01` → `02` → `03` → `04`. Ноутбук `02` создаёт `data/processed/`, остальные его используют. `NN.ipynb` запускается после `02`, из корня проекта.
